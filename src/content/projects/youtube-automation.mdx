# YouTube Automation Pipeline

## Overview

Built an automated pipeline for processing YouTube videos, extracting metadata, and performing content moderation checks.

## Components

### Video Processing
- Automatic caption extraction
- Thumbnail generation
- Quality assessment

### Content Analysis
- Sentiment analysis on comments
- Topic modeling on video transcripts
- Spam detection in comments

### Automation
- Scheduled batch processing
- API integration with YouTube Data API
- Cloud storage for processed content

## Technical Stack

- Python (OpenCV, FFmpeg)
- Transformers for NLP tasks
- Google Cloud Platform
- Airflow for orchestration

## Outcomes

Processed over **10,000 videos** with automated quality checks and metadata enrichment.
