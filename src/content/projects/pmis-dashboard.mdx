# PMIS Procurement Dashboard

## Project Background

Built a comprehensive dashboard system to track procurement workflows, monitor SLA compliance, and provide actionable insights for the purchasing team.

## The Problem

The procurement team needed:
- Real-time visibility into workflow stages
- SLA compliance tracking across vendors
- Automated alerts for delayed processes

## Solution

Created a full-stack dashboard with:

### Backend
- Python-based ETL pipeline
- PostgreSQL for data storage
- SLA calculation engine with configurable rules

### Frontend
- Interactive visualizations (Plotly/D3.js)
- Real-time status updates
- Exportable reports (Excel, PDF)

## Key Features

1. **Workflow Tracking**: Visualize each procurement request from initiation to completion
2. **SLA Monitoring**: Automated calculation of process durations and deviations
3. **Vendor Analytics**: Performance metrics grouped by vendor
4. **Alert System**: Email notifications for SLA violations

## Impact

- **60% reduction** in manual reporting time
- **Improved visibility** into bottlenecks
- **Data-driven decisions** for process optimization

## Technologies

- Python, Pandas, SQLAlchemy
- PostgreSQL
- Next.js + React for frontend
- Docker for deployment
