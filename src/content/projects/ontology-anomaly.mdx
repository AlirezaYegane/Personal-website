# Ontology-aware Anomaly Detection Toy Pipeline

## Overview

This project explores how domain knowledge encoded in medical ontologies can improve anomaly detection in Electronic Health Records (EHR).

## The Challenge

EHR data is messy, high-dimensional, and full of noise. Traditional anomaly detection methods struggle because they treat all features equally, ignoring the rich semantic relationships between medical concepts.

## The Solution

By incorporating **medical ontology** (specifically SNOMED CT), we can:

1. **Group related concepts** - Similar conditions share detection strategies
2. **Prioritize features** - Not all abnormalities are equally important
3. **Explain anomalies** - Leverage semantic relationships for interpretability

## Technical Approach

### Data Pipeline

```python
# Simplified pipeline structure
def detect_anomalies(ehr_data, ontology):
    # 1. Feature extraction
    features = extract_features(ehr_data)
    
    # 2. Ontology-based grouping
    grouped = group_by_ontology(features, ontology)
    
    # 3. Anomaly scoring
    scores = compute_anomaly_scores(grouped)
    
    return scores
```

### Key Components

- **Ontology Parser**: Loads SNOMED CT relationships
- **Feature Engineering**: Creates semantically meaningful features
- **Scoring Module**: Combines statistical and knowledge-based signals
- **Visualization**: Interactive dashboard for result exploration
